## Отсутствующие данные
Следующие данные невозможно получить из HTML-страниц списков врачей и требуют либо парсинга отдельных страниц профилей, либо ручного ввода:

1. **Стаж (experience_years)** — не указан в карточках врачей на странице списка
2. **Категория (category)** — не указана в карточках (только КМН определён из поля opis_vrach)
3. **Описание (description)** — доступно только на страницах профилей отдельных врачей
4. **Направления работы** — не структурированы в HTML
5. **Услуги** — привязка врач-услуга отсутствует
6. **Привязка к конкретному филиалу** — врач привязан к отделению, но не к конкретному адресу

## Невозможно подтвердить
