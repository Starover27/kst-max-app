# MAX Clinic App Architecture

## Принципы
- Feature-sliced архитектура для разделения доменной логики и общих абстракций.
- Маршрутизация и провайдеры живут в слое app.
- UI-скрипты и бизнес-логика разбиваются по feature- и entity-слоям.
- Общие типы, API-клиент и UI-компоненты выносятся в shared.

## Слои
- app: точки входа, провайдеры, роутинг.
- pages: композиции экранов и маршрутов.
- widgets: крупные блоки интерфейса, такие как shell и навигация.
- features: сценарии предметной области (авторизация, записи, пациенты).
- entities: модели предметной области и типы данных.
- shared: общие утилиты, клиент API, UI-библиотека.

## План развития
1. Подключить React Router и провайдеры.
2. Добавить состояние приложения через Zustand.
3. Подключить TanStack Query для сетевого слоя.
4. Ввести схемы валидации через Zod и формы через React Hook Form.
5. Постепенно наполнять features и entities без смешивания слоев.
